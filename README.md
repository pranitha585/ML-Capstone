# 23CSE301 Machine Learning Capstone

## Regression Track

### Project Overview

This project is part of the 23CSE301 Machine Learning Capstone Project for the academic year 2026–27.

The Regression Track focuses on building a complete machine learning pipeline for predicting a continuous target variable. The project covers the major stages of a machine learning workflow, including data loading, exploratory data analysis, data cleaning, preprocessing, feature engineering, model training, model comparison, hyperparameter tuning, and evaluation.

### Regression Algorithms

The following regression algorithms are implemented and evaluated:

1. Linear Regression
2. Ridge Regression
3. Lasso Regression
4. ElasticNet Regression
5. Polynomial Regression
6. Decision Tree Regressor
7. Random Forest Regressor
8. Gradient Boosting Regressor
9. Support Vector Regressor (SVR)
10. K-Nearest Neighbors (KNN) Regressor

### Evaluation

The models are compared using:

- R² Score
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- 5-Fold Cross-Validation R² for the best-performing models

Hyperparameter tuning is also performed on selected models to improve their performance.
